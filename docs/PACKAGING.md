## Step-by-Step Submission (on arxiv.org)

1. Create account at https://arxiv.org (use institutional email)
2. **Get endorsed** (see `ENDORSER_REQUEST.txt`):
   - Find a colleague with arXiv history in cs.LG or eess.SP
   - Or rely on automatic endorser system (fallback)
3. Start submission at https://arxiv.org/submit
4. Copy metadata from `ARXIV_METADATA.txt`:
   - Title
   - Authors
   - Abstract (must be ≤ 1920 chars)
   - Comments
   - Subjects: cs.LG (primary) + eess.SP (cross-list)
   - License: CC BY 4.0
5. Upload files:
   - `paper_arxiv.tex`
   - `paper_arxiv.bbl` (or rely on arXiv's auto-bibliography processing)
   - All `figs/*.png`
   - (Or upload the `paper_arxiv.zip` directly)
6. Wait 24-hour hold → check preview → confirm public posting

## Compatibility Notes

### What was changed from `paper_ieee_tmc.tex`:

| Change | Reason |
|---|---|
| `\documentclass[journal,compsoc]{IEEEtran}` → `\documentclass[11pt]{article}` | arXiv generic LaTeX doesn't accept IEEEtran-specific options |
| `\IEEEpubidadjcol` removed | IEEEtran-specific command |
| `\begin{thebibliography}` kept inline | No external .bib file needed |
| Figure paths: `../src/bvp_test/fig.png` → `figs/fig.png` | arXiv requires files in same dir or subdir |
| Removed "Submitted to IEEE TMC" template notes | arXiv metadata goes in Comments field instead |
| Removed "TODO" placeholder in Acknowledgments | arXiv expects clean text |

### What stays the same:
- All body content
- All equations
- All inline citations and references
- All tables
